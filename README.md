# ecs174_clothes_segmentation
Computer vision project for ECS 174 (Computer Vision) using YOLO and DeepFashion2 to detect, classify, and segment clothing items in images.

The first training subset contains 2,000 training images and a fixed 500-image validation set. [Elena’s training handoff](training/DATA_HANDOFF.md) · [Prepare the dataset](preprocessing/README.md#reproduce-the-training-subset) · [Dataset section and class comparison](data/README.md)
